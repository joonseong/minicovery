**2. Purpose and target audience**
Minicovery (미니커버리) is a micro-learning app for Korean adults who are curious and want to broaden their general knowledge in a few minutes a day. The user types any topic they are curious about (e.g. behavioral economics, wine, Roman history) and chooses their level. The app builds a short course and delivers one 3–5 minute reading ("Drop") per day. It solves the problem that learning a new subject usually takes long books or courses; Minicovery turns it into a short daily habit, with a quick recap of yesterday's reading and a weekly review to help users remember.

**3. How to access the main features**
- No login is required. On first launch, type a topic on the start screen, choose a level, and tap "코스 만들기". Today's Drop opens on the Home tab.
- Optional sign-in: Sign in with Apple, Google, Kakao, or email (Profile › Settings › 로그인 계정). Demo account (email login): `[email]` / `[password]`
- Free users can have one course in progress and read one Drop per day.
- Paid content: Minicovery Plus (auto-renewable monthly subscription, ₩3,900, 7-day free trial for first-time subscribers). It lets the user start 3 new courses per month and unlock all Drops of one course once per month. It is purchased with Apple In-App Purchase from the Plus screen (Profile › Settings › 미니커버리 Plus). "Restore Purchase" is on the same screen.
- Account deletion: Profile › Settings › 계정 삭제 → 삭제하기. It permanently deletes the account and all learning data.
- Reporting content: at the bottom of each Drop, tap "내용이 이상해요" to report incorrect or inappropriate AI-generated content; reports are reviewed by the operator.
- The only content made by other users that the app shows is "recommended courses": courses that users finished and agreed to share, and that the operator reviewed and selected manually. Users cannot post comments or messages.

**4. External services**
- Anthropic Claude API (AI service): generates course outlines and Drops, with Anthropic's web search tool to check facts.
- Supabase (database, Seoul region): stores accounts and learning data.
- Vercel: hosts the app's web content and server API.
- Firebase Cloud Messaging: daily reading reminders (push notifications, opt-in).
- Sign in with Apple, Google Sign-In, Kakao Login: optional authentication.
- Apple In-App Purchase and App Store Server API: Minicovery Plus subscription.

**5. Regional differences**
The app is currently available in Korea only, and its UI and content are in Korean. The app functions the same way for all users.

**6. Regulated industry / third-party material**
Not applicable. The app is not in a regulated industry. Course content is generated by AI for each user and does not include protected third-party material.
